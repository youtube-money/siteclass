این پرامپت رو کپی کن و به هر ابزار AI بده تا برات بازی با کیفیت خوب بسازه:

Create a single-file HTML/CSS/JS browser game (no external libraries).

Visual requirements to match our class site's quality bar:
- High-resolution canvas rendering (crisp on retina displays, no blurry pixels)
- Vibrant neon color palette (violet #8b5cf6, cyan #06b6d4, emerald #10b981 — pick 2-3, not all)
- Smooth animations (60fps, subtle glow/particle effects on key actions like scoring)
- Clean modern UI: score display, game-over screen with restart button
- Fully self-contained in one .html file, mobile-friendly (touch controls if relevant)

IMPORTANT — this game will run inside a sandboxed iframe with NO access to
cookies, localStorage, sessionStorage, or the network (no fetch/XHR will work
and will silently fail). Do NOT use any of those.

To report the final score to the parent site when the game ends, call exactly this
(replace SCORE_VALUE with the numeric final score):
  window.parent.postMessage({ type: 'game-score', score: SCORE_VALUE }, '*');

Call it once, right when the game-over screen appears.

Output only the complete HTML file.
